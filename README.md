# CtrlP Print Shop for Windows

Installers for the CtrlP Print Shop desktop app, which shops use to receive and print CtrlP orders.

## Download

**[Download the latest installer](https://github.com/smarty-code/meetctrlp-exe/releases/latest/download/CtrlP-Print-Shop-Setup.exe)**

Older versions are on the [Releases](https://github.com/smarty-code/meetctrlp-exe/releases) page. Each release lists the SHA-256 checksum of its installer.

## Install

1. Run `CtrlP-Print-Shop-Setup.exe` on the shop's PC (Windows 10 or 11, 64-bit).
2. If Windows SmartScreen shows "Windows protected your PC", choose **More info**, then **Run anyway**.
3. Open CtrlP Print Shop and sign in with your shop account.

The installer sets up the app and its print agent for the current Windows user. No admin rights are needed.
